# Text Expander Plus ⚡


## Features
- **Word count**: live `words · chars` counter under the popup playground (counts the selected portion when you select text), and **Count words in selection** in the right-click menu — shows a small toast with counts without modifying the page.
- **Auto text expander**: define shortcuts like `brb` → `be right back`. Type shortcut + `Space`/`Tab`/`Enter`/punctuation in any input, textarea, Gmail, Docs, etc. to expand. Toggle on/off from popup.
- **Reverse (abc → cba)**: reverse selected characters.
- **Reverse word order**: `hello big world` → `world big big hello` (preserves spacing).
- **Scramble / scramble words**: Fisher–Yates shuffle, keeps working when shuffle returns identical string.
- **UPPER / lower / Title Case**.
- Access via: right-click menu on selection, `Alt+R` / `Alt+S` shortcuts, popup playground, or "Apply to page selection".
